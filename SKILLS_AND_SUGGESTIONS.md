# 🎯 Project 2 — Skills & GitHub Suggestions

## 💼 Skills Demonstrated

### Machine Learning & Data Science Skills
- **Text Classification** — Binary sentiment classification on 50,000 reviews
- **NLP Pipeline** — End-to-end text preprocessing (lowercasing, HTML removal, stopwords, lemmatization)
- **Feature Engineering** — TF-IDF vectorization with unigrams & bigrams (ngram_range=(1,2))
- **Model Comparison** — Systematic evaluation of 5 classifiers under identical conditions
- **Hyperparameter Tuning** — GridSearchCV with StratifiedKFold cross-validation
- **Model Persistence** — Saving/loading models with `joblib`

### Algorithms Implemented
- **Naive Bayes** (Multinomial) — Probabilistic text classification
- **K-Nearest Neighbors** — Cosine distance for sparse TF-IDF vectors
- **Decision Tree** — Depth-controlled to prevent overfitting
- **Random Forest** — Ensemble learning with parallel training
- **Artificial Neural Network (MLP)** — Multi-layer perceptron with early stopping

### Evaluation & Validation Skills
- **Multi-metric Evaluation** — Accuracy, Precision, Recall, F1-Score, Sensitivity, Specificity, ROC-AUC
- **Confusion Matrix Analysis** — Error pattern identification
- **5-Fold Cross-Validation** — Generalization assessment
- **Overfitting Detection** — Train vs. test performance comparison

### Python & Tools
- **scikit-learn** — Full ML pipeline (preprocessing, models, evaluation, tuning)
- **NLTK** — Stopword removal, WordNet lemmatization
- **pandas / numpy** — Data manipulation
- **matplotlib / seaborn** — Visualization
- **WordCloud** — Linguistic feature visualization

### Research Skills
- **Literature Review** — BERT, XLNet, CNN-based approaches (Devlin 2019, Yang 2019, Kim 2014)
- **Benchmark Comparison** — Results contextualized against state-of-the-art (BERT: 95.49%, XLNet: 96.21%)
- **Critical Analysis** — Limitations identified (domain specificity, shallow representations, scalability)
- **Academic Writing** — Structured report with EDA, methodology, results, discussion
